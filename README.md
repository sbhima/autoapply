# AutoApply

Mobile + Desktop automated job application filler supporting **Greenhouse**, **Ashby**, **Lever**, **Workday**, **SmartRecruiters**, **iCIMS**, **BambooHR**, **Jobvite**, **Rippling**, **Dover**, **Workable**, and more.

## Features
- **Multi-User Workspaces**: Click **User** in the top bar to set your username and optional passcode — your resume, profile, saved answers, and history stay isolated.
- **Phone & Laptop Ready**: View live browser screenshots, inspect/edit form fields, choose dropdown options, and advance or submit applications from your phone or laptop.
- **Bring Your Own API Key (or 0-Token Free Mode)**: Supports Google Gemini, OpenAI, and Anthropic with strict per-call and per-session token budgets, or 100% free deterministic rule-only mode.
